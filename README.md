# Pendências System - Website App

Web dashboard for viewing and exporting pendências data with group organization and Excel export.

## Deployment on EasyPanel

### 1. Create New Service
- Service Type: **Application**
- Name: `pendencias-website`
- Source: Upload this `website-app` folder

### 2. Environment Variables
```
FLASK_ENV=production
SECRET_KEY=your-secure-secret-key-here
DB_SERVER=your-database-server
DB_NAME=your-database-name
DB_USER=your-database-user
DB_PASSWORD=your-database-password
OUTPUT_DIR=/app/output
PORT=5000
```

### 3. Port Configuration
- **Internal Port**: 5000
- **Public Port**: Set in EasyPanel (usually auto-assigned)

### 4. Resources
- **Memory**: 1GB (recommended)
- **CPU**: 1 core (recommended)
- **Storage**: 2GB for output files and caching

### 5. Features
- ✅ Interactive dashboard with group organization
- ✅ Historical data visualization (3-day evolution)
- ✅ Excel export functionality
- ✅ Responsive Bootstrap UI
- ✅ Real-time API endpoints
- ✅ Database integration for dynamic group loading

### 6. Endpoints
- `/` - Main dashboard
- `/grupo/<id>` - Group details page
- `/export/excel` - Excel export
- `/api/stats` - Statistics API
- `/api/evolucao/<id>` - Evolution data API

### 7. Dependencies
The website requires access to the same database as the scheduler and the output files generated by the scheduler.
